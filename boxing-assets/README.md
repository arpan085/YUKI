# Boxing Assets Pack

This folder contains a local boxing game asset starter pack created for a polished 2D boxing game prototype.

## Included assets
- Fighter sprite sheets for two visually distinct boxers
- Boxing ring background with ropes, corner posts, and arena floor
- Crowd background for arena atmosphere
- Punch impact, spark, dust, and knockdown effect assets
- UI assets for health, stamina, round indicator, KO banner, and victory/defeat panels
- Fonts CSS file for arcade/sports-style UI typography
- Placeholder generated audio files for punches, bell, crowd, menu, KO, and round results
